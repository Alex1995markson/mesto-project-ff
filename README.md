# Проектная работа Mesto

## Описание проекта
Mesto — это интерактивный сервис для добавления, удаления и лайкинга фотографий. В рамках проекта предстоит реализовать функционал работы с карточками через JavaScript.

## Макет
- [Макет в Figma](https://www.figma.com/file/...) (если не открывается, скачайте [архив .fig](ссылка) или используйте [прямую ссылку](ссылка))
  
  ![Превью макета](https://example.com/preview.jpg)

## Функциональность
1. **Создание карточек**:
   - Используется шаблон `#card-template`
   - Данные берутся из массива `initialCards` (`scripts/cards.js`)
   - Карточки отображаются в блоке `.places__list`

2. **Удаление карточек**:
   - Реализовано через иконку корзины
   - Удаление происходит без сохранения состояния (после перезагрузки карточки восстанавливаются)

## Технологии
- HTML5, CSS3
- JavaScript (ES6+)
- Figma (для работы с макетом)
